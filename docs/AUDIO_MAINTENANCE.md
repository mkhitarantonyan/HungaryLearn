# Обслуживание аудио

## Текущее действие

На 3 октября 2026 года остаётся одна подтверждённая задача: заново записать `public/audio/1.11.mp3`. Видимый итоговый текст урока 1 был исправлен после публикации трёх listening-записей, поэтому существующая narration больше не соответствует карточке.

До появления реальной записи MP3 не заменять синтетическим TTS и не менять manifest вручную.

## Замена записи

1. Сверить финальный learner-facing текст слайда и текст записи.
2. Записать живой голос и заменить только соответствующий MP3.
3. Для listening использовать отдельный listening asset; narration слайда не является заменой comprehension audio.
4. Пересоздать manifest и проверить все связи:

```powershell
npm run generate:manifest
npm run verify:audio
npm run validate:listening
npm run build
```

`scripts/verifyAudioLinks.mjs` — основной сквозной валидатор. Он проверяет физические MP3, lesson slides, `slideAudioManifest.ts`, `audioRegistry.ts`, listening plan, `wordAudioMap.ts`, размеры файлов и hash-версии.

## Правила хранения

- Не хранить списки переозвучки после выполнения: незакрытые пункты переносятся в этот документ или issue, завершённые подтверждаются manifest и тестами.
- Не добавлять дублирующие одноразовые аудио-аудиторы. Новая постоянная проверка расширяет `verifyAudioLinks.mjs` и получает тест или npm-команду.
- Не коммитить исходники записи, промежуточные экспорты и временные WAV, если они не являются согласованными production assets.
