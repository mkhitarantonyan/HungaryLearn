## Runtime decision

P4 adds no runtime vocabulary card, vocabulary ID, alias, `wordAudioMap` entry, or MP3. Candidates should enter SRS only after lexical review and matching human-produced word audio are available. Functional chunks should be selected by communicative usefulness rather than copied wholesale into SRS.
