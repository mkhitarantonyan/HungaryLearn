# P6A vocabulary audit — L21–L24

This audit separates future SRS-worthy core vocabulary from lesson-only
functional chunks and receptive items. Existing vocabulary IDs and
compatibility aliases are preserved. P6A does not publish the `CORE` candidates
as runtime cards because every clickable vocabulary item requires a physical
word MP3, while P6A explicitly freezes all MP3 files. The candidates remain in
the approved lesson texts and are ready for a later vocabulary/audio package.
